FAQ Interaktif

Apa itu HTML?
HTML adalah bahasa markup untuk membuat halaman web.
Apa itu CSS?
CSS digunakan untuk memperindah tampilan web.
Apa itu JavaScript?
JavaScript membuat halaman web menjadi interaktif.
Apa itu jQuery?
jQuery adalah library JavaScript untuk memudahkan DOM manipulation.
Apa itu API?
API adalah antarmuka untuk menghubungkan aplikasi dengan data/software lain.
